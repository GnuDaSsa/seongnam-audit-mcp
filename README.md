# 성남시 감사정보 MCP

성남시의 공개 감사사례에서 업무가 지적된 이유와 당시 조치를 검색한다. 답변하기 전에 사례별 공식 원문을 다시 읽고 인용할 문구와 위치를 검증한다. 사용자 설명과 과거 감사에서 인정한 사실은 구분한다.

- [성남시청 분야별 감사사례](https://www.seongnam.go.kr/pm030305)
- [감사자료 수록·검색·원문 검증 이슈](https://github.com/GnuDaSsa/seongnam-audit-mcp/issues)

이 저장소에서 정책, 수집기, 검색 코드, 배포 구성과 검증 하네스를 관리한다. 수집한 원본 파일과 검색 스냅샷은 저장소에서 제외한다.
