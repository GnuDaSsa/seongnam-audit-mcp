## 누가 무엇을 평가했나

출제자가 먼저 문항과 턴별 판정표를 만들고 SHA-256을 고정했다. 별도의 Codex 답변 작성자는 질문과 MCP 검색 결과를 바탕으로 한국어 첫 답변을 작성했다. 출제자가 고정된 답변을 정답표와 원문에 대조해 각 턴의 정확성과 유용성을 채점했다. 다른 공식 사례를 인용해도 필수 사실과 적용 범위를 원문이 뒷받침하면 인정하는 기준이다. 질문은 공개사례로 구성한 평가용 시나리오다. 실제 시민 설문, ChatGPT 웹 화면의 첨부 처리, OCR 문자 인식률은 별도 평가가 필요하다. [질문](../benchmarks/answer/questions.json) · [출제 시점과 해시](../benchmarks/answer/frozen.json) · [판정표](../benchmarks/answer/key.json)

정확성은 사실·금액 경계·기관·조치가 원문과 일치하는지, 과거 감사의 판단을 현재 사안에 적용할 조건을 구분하는지로 판정했다. 실무 유용성은 질문에 직접 답하고 이용자가 다음에 확인할 자료나 취할 조치를 안내했는지로 판정했다. 대화는 모든 턴이 통과해야 1건으로 집계한다. 금액을 정정한 둘째 턴에서 설명을 보완해도 첫 턴의 점수는 유지한다. [턴별 채점 기록](../benchmarks/answer/review.json)

사례를 인용한 답변 6개에서 공식 본문 5건의 인용 위치·문구·URL을 대조했다. 원문 재조회 검사는 답변에 실제로 적힌 증거를 검색 이력과 연결하고, 해당 위치의 원문을 다시 연 뒤 최종 대조 도구로 검증한다. 개인별 확률을 물은 마지막 질문에서는 검색 결과가 있어도 근거 부족을 설명하고 추가 사실을 요청한 점을 평가했다. [최초 답변과 검색·인용 기록](../benchmarks/answer/first-answers.json) · [검사 코드](../answer-benchmark.mjs)

## 의료원 계약 첫 질문의 재검사

수정 후 공개 MCP에서 별도의 작성자가 `answer-02`의 첫 질문에 다시 답했다. 이전 대화와 정답표는 제공하지 않았다. 답변은 2,000만 원을 당시 기준의 ‘이하’에 포함시키고, 이번 계약에 대해서는 체결일에 의료원 계약사무 규정 제25조·제32조·제33조가 같은 내용으로 시행 중이었는지를 확인 조건으로 특정했다. 금액 기준에 관해 물은 이 턴의 정확성과 실무 유용성은 각각 1/1이었다. 평가자가 시청 본문을 다시 열어 금액 경계와 실제 지적에 관한 두 문구를 최종 대조했다. 별도 적용 예외나 계약 전체의 적법성을 확인한 결과는 아니다. [재답변 전문·근거·채점](../benchmarks/answer/contract-recheck.json)

이 문항은 첫 측정 뒤 공개되었다. 새 답변은 알려진 실패 한 건을 다시 검사한 기록이다. 최초 평가 결과는 정확성 6/6, 실무 유용성 5/6이며, 새 대화에서 95% 목표를 달성하는지는 별도의 미공개 질문으로 검사해야 한다.

## 재현

저장소 루트에서 첫 명령은 질문·정답·답변의 지문을 검사한다. 둘째 명령은 공개 MCP에서 기록된 검색과 원문 대조를 다시 실행하고 정확성 및 유용성 목표를 검사한다. 첫 결과의 유용성 5/6이 그대로인 경우 전체 검사 종료 코드는 1이다. 세 번째 명령은 유용성 목표를 적용하지 않고 원문 재조회 성공 여부를 별도로 검사한다.

```sh
node answer-benchmark.mjs --check-freeze
node answer-benchmark.mjs --output answer-results.json
node answer-benchmark.mjs --replay-only
```

이 명령들은 같은 답변의 근거를 다시 검사한다. 개선 후의 첫 답변을 평가하려면 질문과 정답을 새로 동결하고, 정답을 보지 않은 작성자가 답한 뒤 별도로 채점해야 한다.
