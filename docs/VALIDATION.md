실무 유용성은 당시 지적, 현재 사안과 다른 점, 담당자가 확인할 증빙까지 답했는지 평가한 값이다. 최초 5/6은 예산 MCP에서 쓰던 95% 기준에 미달했다. 실제 이용자 설문과 동시 접속 부하 측정은 수행하지 않았다. 회귀군의 성적은 수정에 이미 사용한 질문에서 다시 나타난 결과다. 지정 원문 대조는 검색 성공과 별도로 모든 양성 문항에서 수행하므로 검색이 빗나가도 원문 점수는 높을 수 있다. [문항별 검색 결과](BENCHMARK.md) · [첫 답변과 채점 근거](ANSWERS.md)

추가 독립 답변군은 소규모로 설정한 95% 기준을 충족했다. 독립 검색군에서는 불충분한 질문에 대한 보류가 기준에 미달했다. 두 평가에는 서로 다른 질문이 들어 있다. 운영 성능을 추적하는 공개 이슈에 실패 질문과 기대 동작을 남겼다. [후속 이슈 #7](https://github.com/GnuDaSsa/seongnam-audit-mcp/issues/7)

## 첨부 자료의 확인 범위

한국어 합성 문서 한 쪽을 PNG, 텍스트 PDF, 스캔 PDF로 각각 만들었다. Windows 한국어 OCR 또는 PDF 텍스트 추출로 업무 사실을 읽고 가상 관리번호를 제외한 뒤 ‘물품구매 분할계약’만 공개 MCP로 보냈다. 세 형식 모두 검색 → 원문 → 최종 대조를 통과했다. 실제 발신 요청에는 파일·관리번호가 없었고 세 경로에서 같은 공식 인용과 본문 해시를 확인했다. 초안에서는 ‘두 차례’를 ‘두 사례’로 잘못 읽어 원본 사실 확인 단계에서 중단된 경우도 있었다. 숫자나 결재일을 잘못 읽으면 유사 사례가 달라질 수 있다. [성남시 원문](https://www.seongnam.go.kr/pm030305/2136)

파일 인식은 첨부를 받은 호스트에서 수행한다. 이번 측정 범위는 한 쪽짜리 인쇄체 합성 자료와 Windows 호스트이며, ChatGPT 파일 업로드 화면·필기·흐릿한 사진·복잡한 표의 정확도는 측정하지 않았다. [첨부 시험 재현 방법](../examples/attachment-smoke/README.md)
