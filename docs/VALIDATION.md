# 성남시 감사정보 MCP 1.1.0 검증 결과

2026년 11월 25일, 로그인 없는 공개 MCP에서 시청 감사사례 1,717건을 대상으로 실행했다. 검색 자료의 SHA-256은 `7cb4a32048bdaa2d6b25a3f7f0f95f98a499bb24625fbbff9f465df6c6fc7380`이며 로컬 비교군과 일치했다. 예산 MCP의 질문·정답 사전 동결, 첫 답변 보존, 독립 채점, 후속 질문과 최종 원문 대조를 감사사례에 적용했다. 예산 총액·추경·부서별 금액 검산은 예산 서비스에서 수행하는 검사다. 감사 MCP는 기관·감사연도·처분 내용과 인용 위치를 확인한다. ## 검색과 완성된 답변

| 평가 자료 | 처음 실행 | 수정 후 같은 질문을 운영 서버에서 재실행 |
|---|---|---|
| 개발·보류 질문 40개 | 개발·보류군의 보류 정답 각 3/4. 보류군 상위 3건 적중 16/16 | 두 군 합산 상위 3건 적중 30/32, 보류 8/8, 지정 원문 32/32 |
| 이후 별도 동결한 예비 질문 16개 | 상위 3건 적중 10/12, 상위 5건 12/12, 보류 3/4, 원문 12/12 | 양성 12문항의 순위 유지. 범위 밖 바이올린 질문까지 보류해 4/4 |
| 첫 한국어 답변 6개 대화·7개 발화 | 대화별 정확성 6/6, 실무 유용성 5/6. 발화별 7/7, 6/7 | 원래 7개 발화의 근거 재현. 의료원 2,000만 원 문항만 새 작성자가 다시 답했을 때 계약 체결일의 적용 규정을 특정해 해당 문항 1/1 |

실무 유용성은 당시 지적, 현재 사안과 다른 점, 담당자가 확인할 증빙까지 답했는지 평가한 값이다. 최초 5/6은 예산 MCP에서 쓰던 95% 기준에 미달했다. 실제 이용자 설문과 동시 접속 부하 측정은 수행하지 않았다. 회귀군의 성적은 수정에 이미 사용한 질문에서 다시 나타난 결과다. 지정 원문 대조는 검색 성공과 별도로 모든 양성 문항에서 수행하므로 검색이 빗나가도 원문 점수는 높을 수 있다. [문항별 검색 결과](BENCHMARK.md) · [첫 답변과 채점 근거](ANSWERS.md)
